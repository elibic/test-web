# apps-script — ניטור והתראות מרכזי (Google Apps Script)

שכבת ההתראות ה"תמיד-חיה" לכל מעליות השבת, בגישת **Google Apps Script** — **סקריפט אחד
לכל הפרויקטים**. שולח מייל דרך `MailApp` ישירות מחשבון ה-Google שלך (**בלי SMTP, בלי
סיסמת-אפליקציה, בלי Blaze**). רץ בענן של Google ולכן עובד גם כש-ה-Pi כבוי / הפסקת-חשמל.

> זו החלופה הפשוטה ל-`functions/` (Cloud Functions). **אל תפעיל את שתיהן יחד** — תקבל
> התראות כפולות. `functions/` נשאר בריפו כאופציה (טריגרים מיידיים), לא חובה.

## איך זה עובד
- הסקריפט קורא את **רשימת הפרויקטים + ההגדרות-פר-פרויקט** מ-hub האדמין
  (`econtrolelevelev` → `/projects/<id>/notifications`).
- את ההגדרות מנהלים **מהדשבורד** — כפתור **"🔔 התראות"** בכל כרטיס פרויקט (נמענים, אילו
  אירועים, סף "אין תנועה", שעות לילה, וטלגרם). הסקריפט עצמו לא צריך עריכה פר-פרויקט.
- לכל פרויקט הוא קורא את ה-DB שלו (`/elevators`, `/elevator_configs` — קריאה ציבורית, בדיוק
  כמו שהדשבורד והתצוגות הציבוריות קוראים), ושולח שלוש התראות:
  1. 🕯️ כניסה למצב שבת · 2. ✅ יציאה ממצב שבת — לפי `elevator_configs/{id}/SHABBAT_ACTIVE`.
  3. ⚠️ אין תנועה X שעות (החרגת לילה) — לפי `elevators/{id}/timestamp`; תופס גם הפסקת-חשמל.
- המצב הקודם נשמר ב-PropertiesService לפי `<project>/<elevator>` — **אין כתיבה ל-Database**.

## התקנה (פעם אחת, ~5 דקות)
1. **https://script.google.com** → **New project**. מחק את הדוגמה והדבק את כל `elevator-monitor.gs`.
2. השג **database secret** של `econtrolelevelev` והדבק ב-`ADMIN_DB_AUTH` בראש הקובץ:
   Console → ⚙️ **Project settings** → **Service accounts** → **Database secrets** → **Show** → העתק.
   (דרוש כי `/projects` מאחורי הרשאה — שם נמצאות ההגדרות וכתובות-ה-DB של כל פרויקט.)
3. ודא אזור-זמן: **Project Settings (⚙️) → Time zone → (GMT+02:00/03:00) Jerusalem**.
4. **בדיקה מיד:** בחר את `sendTestAlert` בסרגל העליון → **Run** → אשר הרשאות (מייל + רשת).
   אמור להגיע מייל-בדיקה לנמען הראשון שהגדרת בדשבורד, וב-**Executions** תראה את רשימת הפרויקטים.
5. **טריגר מתוזמן:** ⏰ **Triggers** → **Add Trigger** →
   - Function: `monitorElevators`
   - Event source: **Time-driven** → **Minutes timer** → **Every 5 minutes** → **Save**.

מכאן הוא בודק לבד כל 5 דקות את **כל** הפרויקטים ושולח מייל בעת אירוע — לפי ההגדרות שבדשבורד.

## הוספת פרויקט חדש
**שום שינוי בסקריפט.** מוסיפים את הפרויקט בדשבורד, פותחים **🔔 התראות**, מגדירים נמענים — וזהו.

## עמידות לתקלות-רגע
- כל קריאות ה-Firebase עוברות דרך `fetchWithRetry` - עד 3 נסיונות חוזרים עם backoff מעריכי
  (1ש'/2ש'/4ש') על תקלת-רשת חולפת או תשובת `5xx/429`. שגיאה לא-חוזרת (כמו `401/404`) לא
  מנוסה שוב. כך גמגום-שרת בודד מתאושש בתוך אותה הרצה במקום להפיל אותה.
- אם בכל זאת מגיע מייל-כשל של Google ("a server error occurred") - זו לרוב תקלת-תשתית רגעית
  של Apps Script שאינה ניתנת ללכידה מתוך הקוד; ההרצה הבאה (בעוד ~5 דק') מתאוששת לבד.
- בלוג-ההרצה (Executions) נסיון-חוזר נראה כשורת `נסיון N ל-... → HTTP ...`. הרצה שרשמה
  נסיון-חוזר אך הסתיימה ב-`Completed` = העמידות עשתה את שלה.

## הערות
- בלוגים `/projects → HTTP 401 / Permission denied` ⇒ `ADMIN_DB_AUTH` חסר או שגוי.
- אם `/elevator_configs` של פרויקט מסוים מחזיר Permission denied — ה-DB שלו אינו קריא-ציבורית
  (שאר הפרויקטים כן); יש לפתוח קריאה ל-`/elevators`+`/elevator_configs`, או דווח.
- לראות לוגים: בעורך → **Executions** (▶️ בתפריט השמאלי).
- מכסות Apps Script (מאות מיילים/יום, אלפי קריאות-רשת/יום) — הרבה מעבר לצורך.
- **ההגדרות חיות בדשבורד בלבד** — לא בקוד ולא ב-Pi (שכבת ההתראות הוסרה מה-Pi).
